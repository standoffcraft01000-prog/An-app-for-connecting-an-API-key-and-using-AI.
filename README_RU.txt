GikAI Desktop — версия 0.3.1
============================

Что умеет эта версия
--------------------
- Тёмный интерфейс чата с зелёными элементами.
- Настройки своего API-провайдера, модели и Base URL.
- Отправка сообщений и истории текущего чата в API.
- Исправлена ошибка Tkinter `bad screen distance "0 11"`, из-за которой сообщение не отображалось и запрос не отправлялся.
- Поддержка OpenAI, OpenRouter и других OpenAI-совместимых API.
- Отдельная поддержка Google Gemini через стандартный generateContent API.
- Кнопка «Проверить API» показывает, работает ли ключ, модель и адрес сервера.
- Сетевые запросы выполняются в фоновом потоке, интерфейс не должен зависать во время ответа.
- API-ключ хранится через системное хранилище учётных данных (keyring), а не в settings.json.
- Ошибки авторизации, адреса и ответа API показываются в чате.

Пока ещё нет
------------
- Постоянной памяти между запусками приложения.
- Сохранения истории чатов на диск.
- Генерации изображений и голосового общения.
- Автоматического выбора модели: укажи точный ID модели, доступный у твоего провайдера.

Как подключить API
------------------
1. Запусти GikAI через run_windows.bat или собери EXE.
2. Открой «Настройки API».
3. Выбери провайдера.
4. Укажи точный ID модели, который доступен в твоём API-аккаунте.
5. Проверь Base URL. Для OpenAI, OpenRouter и Gemini приложение подставляет стандартный адрес при выборе провайдера.
6. Вставь API-ключ в поле и нажми «Сохранить настройки».
7. Нажми «Проверить API». Если тест прошёл, перейди в чат и отправь сообщение. Если нет — окно покажет текст ошибки, который поможет понять причину.

OpenAI и OpenRouter используют формат Chat Completions (/chat/completions).
Для другого совместимого сервиса укажи его API Base URL, обычно заканчивающийся на /v1.
Google Gemini использует стандартный REST endpoint /models/{model}:generateContent и заголовок x-goog-api-key. История текущего чата передаётся через contents с ролями user/model.

Безопасность и расходы
----------------------
- Не отправляй API-ключ в чат и никому его не показывай.
- Не вставляй ключ в исходный код и не присылай его сюда.
- На Windows ключ сохраняется в системном хранилище учётных данных через keyring.
- Файл %APPDATA%\\GikAI\\settings.json содержит только настройки провайдера, модели и Base URL.
- API-запросы могут расходовать квоты или средства аккаунта у провайдера. Проверь лимиты/условия в аккаунте и согласуй платное использование со взрослым.
- История диалога сейчас находится только в памяти приложения и очищается при закрытии или создании нового чата.

Как запустить из исходников
---------------------------
1. Установи Python 3.11 или новее для Windows.
2. Распакуй архив.
3. Запусти run_windows.bat.

Как собрать GikAI.exe
---------------------
1. На Windows установи Python 3.11 или новее.
2. Распакуй архив.
3. Дважды щёлкни build_windows.bat.
4. Готовый файл появится в dist\\GikAI.exe.

Почему EXE нужно собирать на Windows
------------------------------------
Google Colab работает в Linux-среде. PyInstaller собирает приложение под ту ОС,
в которой запущен, поэтому обычный Windows EXE следует собирать на Windows.
Colab можно использовать для редактирования и хранения исходного проекта.

Проверка формата запросов (без реального API и без ключа)
---------------------------------------------------------
В папке проекта выполни:
    python -m unittest -v test_api.py
